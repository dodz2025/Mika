# CRA GLB generator

This repository now includes a procedural generator for a low-poly red sedan model matching the reference vehicle style.

## Usage

```bash
python3 generate_cra_glb.py
```

This creates `cra.glb` in the repository root.

## Notes

- The model is approximate, built from geometric primitives to match the vehicle’s silhouette and proportions from the provided photos.
- It is intentionally lightweight for use in web or AR viewers.
